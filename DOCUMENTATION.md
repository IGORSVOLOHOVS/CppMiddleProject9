# Документация проекта Mandelbrot Fractal

## 1. Обзор проекта

### 1.1. Краткое описание и цели

**Mandelbrot Fractal** — это десктопное приложение, предназначенное для генерации и интерактивной визуализации множества Мандельброта. Проект демонстрирует использование современных техник программирования на C++ для создания производительных графических приложений.

**Основные цели проекта:**
- Создать точную и быструю визуализацию множества Мандельброта.
- Предоставить пользователю интуитивно понятные инструменты для исследования фрактала.
- Служить образовательным примером использования C++23, библиотеки SFML для графики и `stdexec` для асинхронного программирования.

### 1.2. Ключевые функции

- **Интерактивная визуализация:** Отображение множества Мандельброта в реальном времени.
- **Масштабирование:** Плавное приближение и отдаление с помощью колеса мыши для детального изучения фрактала.
- **Панорамирование:** Перемещение по фракталу с помощью перетаскивания мышью.
- **Динамическая детализация:** Увеличение числа итераций при приближении для повышения качества изображения.
- **Цветовые схемы:** Использование цвета для наглядного отображения "скорости" ухода точки в бесконечность.

### 1.3. Целевая аудитория

- **Энтузиасты математики и фрактальной геометрии:** Люди, интересующиеся визуальным исследованием математических объектов.
- **Студенты и начинающие разработчики:** Те, кто изучает C++, компьютерную графику и параллельное программирование.
- **Разработчики на C++:** Специалисты, ищущие примеры применения современных библиотек и подходов (C++23, SFML, `stdexec`).

## 2. Техническая архитектура

### 2.1. Используемые технологии и фреймворки

- **Язык программирования:** **C++23**. Проект активно использует современные возможности языка.
- **Графическая библиотека:** **SFML (Simple and Fast Multimedia Library)**. Используется для создания окна, обработки пользовательского ввода и рендеринга 2D-графики.
- **Система сборки:** **CMake**. Обеспечивает кроссплатформенную сборку проекта и управление зависимостями.
- **Асинхронное программирование:** **NVIDIA `stdexec`**. Библиотека для построения асинхронных и параллельных исполнительных конвейеров (pipelines). Используется для вычисления фрактала без блокировки основного потока.
- **Тестирование:** **Google Test (GTest)**. Применяется для написания и выполнения юнит-тестов.

### 2.2. Схема взаимодействия компонентов

Архитектура проекта построена на принципах разделения ответственности и асинхронного выполнения задач.

```
[ Пользователь ] -> [ SFML Window ] -> [ SfmlEventHandler ]
      |                                        |
      V                                        V
[ Main Loop (в MandelbrotApp) ]          [ Обновление состояния (AppState) ]
      |                                        |
      V                                        V
[ CalculateMandelbrotAsyncSender ] --(stdexec)--> [ MandelbrotRenderer (Thread Pool) ]
      |                                        |
      V                                        V
[ Рендеринг данных фрактала ]             [ Вычисление итераций ]
      |
      V
[ SFMLRender ] -> [ SFML Image/Texture ] -> [ Отображение на экране ]
```

**Ключевые компоненты:**

- **`MandelbrotApp`**: Главный класс приложения. Инициализирует все компоненты и запускает основной асинхронный конвейер.
- **`SfmlEventHandler`**: Обрабатывает события ввода от SFML (движение мыши, масштабирование, закрытие окна) и обновляет общее состояние приложения (`AppState`).
- **`CalculateMandelbrotAsyncSender`**: Асинхронная операция, которая инициирует вычисление данных для фрактала в фоновом потоке с помощью `MandelbrotRenderer`.
- **`MandelbrotRenderer`**: Управляет пулом потоков и распределяет задачи по вычислению итераций для каждого пикселя.
- **`SFMLRender`**: Получает готовые данные о фрактале и отрисовывает их на текстуре SFML для отображения в окне.
- **`mandelbrot_fractal_utils.hpp`**: Модуль с "чистыми" функциями, содержащими основную математическую логику (вычисление итераций, преобразование координат, окрашивание).

### 2.3. Среда развёртывания

Проект является десктопным приложением и не имеет традиционных сред развёртывания (dev/staging/prod).

- **Среда разработки (Development):** Локальная машина разработчика. Требует наличия компилятора C++ с поддержкой C++23, CMake, SFML и GTest. Поддерживаемые ОС: Linux, Windows, macOS.
- **Среда выполнения (Production):** Любой компьютер конечного пользователя, на котором может быть запущен скомпилированный исполняемый файл.

## 3. Инструкции для разработчиков

### 3.1. Настройка локальной среды разработки

Для сборки и запуска проекта вам потребуется следующее программное обеспечение:

1.  **Компилятор C++ с поддержкой C++23** (например, GCC 13+ или Clang 16+).
2.  **CMake** (версия 3.28 или выше).
3.  **Git** для клонирования репозитория.
4.  **Библиотеки SFML и GTest.**

**Пример установки зависимостей для Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git libsfml-dev libgtest-dev
```

### 3.2. Руководство по запуску проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <имя папки проекта>
    ```

2.  **Создайте директорию для сборки:**
    ```bash
    mkdir build
    cd build
    ```

3.  **Сконфигурируйте проект с помощью CMake:**
    ```bash
    cmake ..
    ```

4.  **Соберите проект:**
    - Для сборки основного приложения:
      ```bash
      make MandelbrotFractal
      ```
    - Для сборки тестов:
      ```bash
      make MandelbrotFractal_tests
      ```

5.  **Запустите приложение или тесты:**
    - Запуск приложения:
      ```bash
      ./MandelbrotFractal
      ```
    - Запуск тестов:
      ```bash
      ctest --output-on-failure
      ```

### 3.3. Структура файлов и папок

-   `src/`: Исходный код основных компонентов приложения (`main.cpp`, `MandelbrotApp`).
-   `include/`: Заголовочные файлы (`.hpp`) с основной логикой, доступные для всего проекта.
    -   `mandelbrot_fractal_utils.hpp`: Чистые функции для вычисления фрактала.
    -   `sfml_events_handler.hpp`, `sfml_renderer.hpp`: Логика взаимодействия с SFML.
-   `tests/`: Юнит-тесты для проекта.
-   `CMakeLists.txt`: Главный файл сборки CMake.
-   `DOCUMENTATION.md`: Эта документация.

### 3.4. Правила именования и стандарты кода

-   **Стиль кода:** Проект придерживается современных практик C++.
-   **Именование:**
    -   Классы и структуры: `UpperCamelCase`.
    -   Переменные и функции: `snake_case`.
    -   Константы и макросы: `UPPER_SNAKE_CASE`.
-   **Заголовочные файлы:** Используйте `#pragma once` для защиты от двойного включения.
-   **Комментарии:** Пишите содержательные комментарии для сложных участков кода.

## 4. Руководство пользователя

### 4.1. Как использовать ключевые функции

После запуска приложения откроется окно с визуализацией множества Мандельброта.

-   **Масштабирование (Zoom):**
    -   Прокручивайте **колесо мыши вперед**, чтобы приблизить изображение и рассмотреть детали фрактала.
    -   Прокручивайте **колесо мыши назад**, чтобы отдалить изображение.

-   **Панорамирование (Pan):**
    -   **Нажмите и удерживайте левую кнопку мыши**, а затем перемещайте курсор, чтобы перемещаться по фракталу.

-   **Выход из приложения:**
    -   Нажмите на **крестик** в углу окна или клавишу **Escape** на клавиатуре.

### 4.2. Описание ролей и прав доступа

Это десктопное приложение для одного пользователя. Концепция ролей и прав доступа к нему не применима.

### 4.3. FAQ (Часто задаваемые вопросы)

**В: Приложение работает медленно при сильном приближении. Это нормально?**
**О:** Да. При сильном приближении требуется гораздо больше вычислений для сохранения детализации (число итераций увеличивается). Это может приводить к снижению производительности, особенно на менее мощном оборудовании.

**В: Почему некоторые области окрашены в сплошной черный цвет?**
**О:** Черные области представляют собой точки, принадлежащие множеству Мандельброта. По определению, эти точки не "уходят" в бесконечность, и алгоритм прекращает их вычисление после достижения максимального числа итераций.

**В: Можно ли изменить цветовую палитру?**
**О:** В текущей версии цветовая схема жестко задана в коде (`IterationsToColor` в `mandelbrot_fractal_utils.hpp`). Для ее изменения требуется модификация исходного кода и пересборка проекта.
